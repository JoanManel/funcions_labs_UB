Llibreria de funcions per representar i ajustar dades a les pràctiques del Grau de Física

En aquesta carpeta teniu la llibreria de funcions "funcions_labs.py" que es l'unica cosa que necessiteu per fer-la servir.
S'inclou un arxiu "Documentacio_funcions_labs.pdf" amb la documentació i alguns exemples.

També hi ha un arxiu de Jupyter Nootebook ("Exemples_f_labs.ipynb") amb més exemples. 
El fitxer Exemples_f_labs.pdf és un pdf le l'anterior script per si voleu veure els exemples sense haver d'obrir Jupyter Nootebook
En aquest script es fan servir algunes dades d'exemple que hi ha a la carpeta "Dades_Exemple".
Necessitareu aquesta carpeta per poder còrrer el script.
